# mobile-invitation

2026.11.07 모바일 청첩장. 단일 정적 페이지(`index.html`)로 구성되어 있으며 별도 빌드 과정이 없습니다.

## 로컬에서 보기

`index.html`을 정적 서버로 열면 됩니다 (file:// 로 직접 열면 상대 경로 이미지가 안 보일 수 있어요).

```bash
npx serve .
```

## 구성

- 표지 → 인사말(+ 2주치 미니 캘린더/디데이) → 오시는 길(카카오맵 + 지하철/버스/자가용+주차) → 갤러리(스와이프) → 방명록 → 마무리(마음 전하실 곳 + 감사 인사)
- 참석 여부 팝업 (스크롤 중 1회 자동 노출, 우측 하단 알약 버튼으로 재오픈, 한 번 제출하면 localStorage로 재노출 방지)
- 우측 상단 BGM on/off 토글 ("Gymnopedie No. 1", Kevin MacLeod, CC BY 4.0 — 하단에 출처 표기)
- 카카오맵으로 오시는 길 지도 표시, 카카오톡 공유 버튼으로 카카오톡 공유 가능
- 방명록·참석여부·계좌번호는 Google Apps Script 웹앱을 통해 Google Sheets에 저장/조회됩니다
  (`SHEET_ENDPOINT` 상수, 스프레드시트 "청첩장 응답 - 진규석 배시연" — Guestbook / RSVP / Accounts 탭)

## 카카오 앱 설정

지도(카카오맵 SDK)와 카카오톡 공유는 카카오 디벨로퍼스의 "웨딩 예산관리" 앱(다른 프로젝트와 공유, 무료 쿼터 보유)의
JavaScript 키를 사용합니다. 도메인을 바꾸게 되면 그 앱의 "플랫폼 키 > JavaScript SDK 도메인"에 새 도메인을 추가해야 합니다.

## Google Apps Script 코드 수정 시

`Code.gs`를 수정한 뒤에는 Apps Script 편집기에서 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 > 배포**를 해야
실제 웹앱 URL에 반영됩니다 (그냥 저장만 하면 반영되지 않아요).

## 남은 작업

- `assets/gallery/`에 사진 추가/교체 시 `index.html`의 `<img>` 목록만 늘리면 됩니다
- Accounts 시트의 계좌번호(현재 000-0000-0000 placeholder)를 실제 번호로 교체
- 오시는 길 지하철/버스 안내 문구 최종 확인
